# Manta Network

> Manta Network is a modular Layer-2 blockchain ecosystem for zero-knowledge (ZK) applications. It comprises Manta Pacific — an EVM-compatible Ethereum Layer-2 rollup built on the OP Stack that uses Celestia for data availability — and Manta Atlantic, a Polkadot parachain focused on on-chain ZK identity and privacy. Developers interact with Manta Pacific via standard Ethereum JSON-RPC (chain ID 169) and with Manta Atlantic via Substrate/Polkadot JSON-RPC over WebSocket.

## Networks / Endpoints

- [Manta Pacific Network Information](https://docs.manta.network/docs/manta-pacific/Build%20on%20Manta/Network%20Information): EVM L2 rollup — RPC https://pacific-rpc.manta.network/http, WSS wss://pacific-rpc.manta.network/ws, Chain ID 169, currency ETH
- [Manta Pacific Sepolia Testnet](https://docs.manta.network/docs/manta-pacific/Testnet%20Info): RPC https://pacific-rpc.sepolia-testnet.manta.network/http, WSS wss://pacific-rpc.sepolia-testnet.manta.network/ws, Chain ID 3441006
- [Manta Atlantic Network Information](https://docs.manta.network/docs/manta-atlantic/Network%20Information): Polkadot parachain (Para ID 2104) — RPC wss://ws.manta.systems, native token MANTA
- [JSON-RPC Nodes](https://docs.manta.network/docs/manta-pacific/JSON-RPC%20Nodes): JSON-RPC node reference for Manta Pacific
